# Regulation archive

One file per past regulation. `reference/regulation.md` always describes the
**current** cycle only; when it rolls over, the outgoing cycle is archived
here by the `vgc-regulation-transition` skill.

Why keep them: team files under `teams/` record the regulation they were
built for. Without the archive, an old team's reasoning becomes
uninterpretable — you can't tell which mechanics were active or which
Pokémon were even available when it was built.
