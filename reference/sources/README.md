# reference/sources/

Frozen source documents. **Nothing in this directory is edited after it lands.**

A working reference file may be rewritten, restructured, or corrected freely.
When that happens, the question "did we drop something the source actually
said?" has to stay answerable — that is what these files are for. Editing them
to match a later rewrite would destroy the only copy of the original claim.

Corrections to a source's factual content belong in the working file that
cites it, with a note recording the substitution. Never here.

| File | What it is | Working files built on it |
|---|---|---|
| `teambuilding-notes.md` | Masterclass notes, foundational, provided 2026-09-08 | `archetypes.md`, `speed-control.md`, `roles.md`, `team-evaluation.md` |
| `teambuilding-notes-advanced.md` | Masterclass notes, advanced, provided 2026-09-08 | same four |
